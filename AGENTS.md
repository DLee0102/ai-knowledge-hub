# AGENTS.md

Guidelines for AI coding agents working in `ai-knowledge-hub`.

## Project Overview

`ai-knowledge-hub` is a zero-backend, zero-build-tool static web app hosted on GitHub Pages for managing, viewing, tagging, and full-text searching standalone HTML knowledge cards (such as pages generated by Gemini / AI Studio).

## Repository Layout

- `index.html`, `404.html`: SPA entry point and GitHub Pages fallback.
- `assets/css/style.css`: Light/dark theme design system (`[data-theme="dark"]`) and responsive layout (mobile breakpoint: `960px`).
- `assets/js/`: Native browser ES Modules:
  - `app.js`: Main controller, state, hash router (`#/article/:id`), upload/edit/delete flows, and shortcuts.
  - `parser.js`: Client-side HTML metadata/text parser, category/tag inference, `<meta>` injection, and index payload builder.
  - `search.js`: Chinese/English full-text search, inline syntax (`tag:`, `cat:`, quoted phrases), weighted scoring, and `<mark>` snippet highlighting.
  - `github-api.js`: Browser GitHub REST & Git Data API client (atomic multi-file commits via Fine-Grained PAT).
  - `storage.js`: `localStorage` preferences + `IndexedDB` (`local` drafts and `synced-cache` / deletion tombstones).
  - `ui.js`: DOM rendering and same-origin `iframe` highlight/outline helpers.
- `data/config.json`: Shared category rules, theme colors, and AI tag dictionary.
- `data/index.json`: Auto-generated article metadata and full-text index.
- `articles/`: Standalone `.html` / `.htm` knowledge files (subdirectories act as fallback categories).
- `scripts/build_index.py`: Zero-dependency Python 3 indexer mirroring `assets/js/parser.js`.
- `.github/workflows/deploy.yml`: Auto-indexes `articles/`, stamps asset `?v=<GITHUB_SHA>` cache-busting tags, and deploys to GitHub Pages.

## Core Rules & Invariants

1. **Zero Build & Zero Dependencies**
   - Keep the frontend in vanilla HTML, CSS, and native ES Modules (no bundler or npm runtime dependencies).
   - Keep `scripts/build_index.py` strictly on Python 3 standard library.
2. **Dual-Engine Index Parity**
   - Any change to metadata extraction (`ai-title`, `ai-category`, `ai-tags`, `description`, `ai-created`, `ai-updated`), category/tag inference weights, slugging, word counting, content truncation (`50000` chars), hashing, or sorting MUST be applied symmetrically to both `assets/js/parser.js` and `scripts/build_index.py`.
3. **Asset Cache-Busting**
   - All local CSS/JS references in `index.html` and relative ES module imports in `assets/js/*.js` MUST retain a `?v=<tag>` query parameter so `.github/workflows/deploy.yml` can stamp `?v=<GITHUB_SHA>` on deploy. Bump the tag consistently when modifying frontend assets.
4. **Security & Isolation**
   - Never commit GitHub tokens, PATs, or credentials to the repository.
   - Escape all untrusted/dynamic text with `escapeHtml()` before interpolating into `innerHTML`.
   - Always render knowledge articles inside `#readerFrame` to keep page styles and scripts isolated.
5. **Atomic Writes & CDN Resilience**
   - Multi-file GitHub writes (add, edit, batch delete) must go through `commitAtomicChanges()` together with updated `data/index.json`, and maintain `IndexedDB` `synced-cache` / `deleted: true` tombstones to bridge GitHub Pages deployment latency.

## Local Development & Verification

- Rebuild search index:
  ```bash
  python3 scripts/build_index.py
  ```
- Serve locally over HTTP (required for ES Modules; do not open `index.html` via `file://`):
  ```bash
  python3 -m http.server 8000
  ```
- Verification checklist before committing:
  - Run `python3 scripts/build_index.py` if `articles/`, `data/config.json`, or indexing logic changed; avoid hand-editing `data/index.json`.
  - For UI/CSS/JS changes, verify in a headless or real browser at both desktop (`> 960px`) and mobile (`<= 960px`) viewports, checking for zero console/page errors.

## Git Conventions

- Use Conventional Commits: `feat(<scope>): ...`, `fix(<scope>): ...`, `docs(<scope>): ...`, `chore(<scope>): ...`.
- Keep changes focused and preserve unrelated existing code and comments.
