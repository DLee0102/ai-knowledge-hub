远程索引维护

如果你通过 git push 新增了 HTML，或刚刚上传完想立即绕过 GitHub Pages CDN 缓存看到最新内容：

查看：如何创建仅限单仓库的 GitHub Token 与开启 Pages 部署
  1. 打开 GitHub 仓库 → Settings → Pages → Build and deployment 的 Source 选择 GitHub Actions（仓库已内置 .github/workflows/deploy.yml，每次提交自动索引并部署）。
  2. 打开 GitHub Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  3. Repository access 选择 Only select repositories 并只勾选本知识库仓库。
  4. Permissions → Repository permissions → 将 Contents 设为 Read and write，点击生成并粘贴到上方输入框。
小技巧：给 Gemini 的可选元信息提示词（不加也能自动识别分类和标签） 
请生成一个单文件、样式美观、支持交互演示的 HTML 来深入讲解【知识点名称】。
请在 <head> 中顺便加入：
<meta name="ai-category" content="分类名（如：核心架构/训练与微调/RAG 与 Agent/推理与部署/多模态与生成）">
<meta name="ai-tags" content="3到6个英文或中文技术标签，逗号分隔">
<meta name="description" content="100字以内的核心摘要">
修改配置后请点击保存
