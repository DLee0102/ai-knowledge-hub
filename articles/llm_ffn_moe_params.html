01

FFN（前馈神经网络）：大模型的非线性大脑与知识仓库

多头自注意力本质上只做了跨 Token 的线性加权平均。没有 FFN，堆叠再多层 Attention 也近似于线性变换，无法完成复杂逻辑推导。FFN 独立作用于每个 Token，通过“先升维摊开特征 → 非线性门控筛选 → 再降维浓缩”完成深度加工，并承载了全模型约 70% 的知识参数。

02

MoE（混合专家架构）：解耦“总参数”与“单步算力”的万亿密码

在稠密模型中，参数越大计算越贵（如 Llama 3 405B 每吐 1 个字都要把 405B 参数全算一遍）。MoE（Mixture of Experts）把单层巨大的 FFN 拆分成 E 个独立专家 + 1 个轻量路由器（Router），每个 Token 只唤醒得分最高的 Top-K 个专家，让模型同时拥有万亿级的总知识库和百亿级的极速推理开销！

演进 ①

细粒度专家拆分

从早期 Mixtral 的 8 选 2（仅 28 种组合），演进为 DeepSeek / Qwen3 / Kimi 的 128~384 选 6~8（组合数超 10¹⁴ 种！），专家分工精细度暴涨。

演进 ②

共享专家隔离

设 1~2 个永远常驻激活的共享专家专门消化基础语法与通用常识，彻底解放路由专家去专攻数学、代码、物理、多语种，消除冗余。

演进 ③

无辅助损失均衡

防止路由坍塌（所有词挤向 1~2 个热门专家）。DeepSeek-V3 弃用干扰主梯度的 Aux Loss，改用动态微调偏置项 bᵢ（过载减、空闲加），均衡且零掉点。

演进 ④

EP 并行与路由重放

不同专家分布在多张 GPU 上，经 All-to-All 通信分发与汇聚；在 RL 后训练阶段还需 Routing Replay 锁死训推路由一致，防止训练崩溃。

03

模型规模与层数（L）、宽度（d）的缩放规律

参数规模 N 不仅由总预算决定，更取决于把预算分配给深度（层数 L）还是宽度（维度 d），以及是否引入 MoE 专家宽度（E）。

核心数学定律：深度线性、宽度平方、扩容立方根 架构设计基石
Dense: N ≈ 12 · L · d² + (1或2) · V · d
MoE: N_total ≈ L · (P_attn + E · P_exp) ｜ N_active ∝ K
  • 深度 L 翻倍 → 参数 × 2（线性增长）；宽度 d 翻倍 → 参数 × 4（平方增长）。
  • 经典宽高比（Aspect Ratio）d / L ≈ 80 ~ 130：若维持宽高比 r = d/L 恒定，则 N ≈ 12r²L³，推导出立方根缩放律——总参数每扩大 8 倍，理想层数 L 与宽度 d 各自同步扩大约 2 倍（如 Llama 3 从 8B→70B：L 32→80，d 4096→8192）。
  • 小模型词表占比陷阱：0.5B~2B 小模型因词表高达 15 万，V·d 往往吃掉全模型 15%~30% 的参数！
同等参数下：“深而瘦” vs. “浅而宽”怎么选？ 工程与智能权衡
维度 更深更瘦 (高 L / 低 d) 更浅更宽 (低 L / 高 d)
能力偏向 多步逻辑与推理更强（如 Qwen3 小/中模型刻意做深） 世界知识记忆容量大、特征不拥挤
推理速度 慢：层间严格串行 + 每层 2 次 TP 通信，延迟高 极快：宽矩阵吃满 GPU Tensor Core，吞吐高
KV Cache 随层数 L 线性翻倍膨胀 加 FFN 宽度或加 MoE 专家 0 增加 KV 显存！
当下共识 小模型（0.6B~32B）做深抠推理；万亿旗舰稳在 60~96 层、靠 MoE 横向爆宽！
