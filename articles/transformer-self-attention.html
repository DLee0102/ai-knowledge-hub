Transformer 自注意力机制与多头注意力深度解析

理解现代大语言模型（LLM）的心脏：从 Q/K/V 语义匹配到并行多子空间特征抽取。

为什么需要自注意力（Self-Attention）？

在 Transformer 出现之前，序列建模主要依赖 RNN 与 LSTM。它们必须按时间步顺序计算隐藏状态，不仅无法在 GPU 上充分并行，而且在面对长距离依赖时会出现梯度消失与信息压缩瓶颈。

自注意力机制彻底抛弃了循环结构，允许序列中的任意两个 Token 直接建立 O(1) 路径长度的语义连接。无论两个词相距 5 个字还是 5000 个字，模型都能动态计算它们之间的关联权重，并根据上下文聚合信息。

Q、K、V 矩阵的直观理解

对于输入序列的词向量矩阵 X，模型通过三个可学习的线性投影矩阵 W_Q、W_K、W_V 生成 Query、Key 和 Value：

Query (Q) · 查询

当前 Token 主动发出的“检索意图”：我现在需要从上下文中寻找哪类语义信息？

Key (K) · 键索引

每个 Token 提供的“语义标签”：我包含什么类型的特征，可供其他词匹配？

Value (V) · 实际值

每个 Token 真正携带的内容表示：一旦匹配成功，我将按注意力权重贡献多少信息。

缩放点积注意力公式

Attention(Q, K, V) = softmax( (Q · KT) / √dk ) · V

为什么要除以 √dk？

假设 Q 和 K 的每个维度分量相互独立，均值为 0、方差为 1，则点积 Q·KT 的方差会线性放大为 dk。 当维度 dk 较大（例如 64 或 128）时，点积数值会变得极大，导致 softmax 进入饱和区，输出接近 one-hot 分布，反向传播时的梯度趋近于 0。 除以 √dk 可以将方差重新归一化回 1，确保训练过程梯度稳定。

多头注意力（Multi-Head Attention）与演进对比

单个注意力头只能在一组线性映射子空间中关注一种关系。多头注意力将隐藏维度 d_model 拆分为 h 个独立子空间（每个维度 d_k = d_model / h），并行计算注意力后再拼接投影，使不同 Head 可以同时捕捉句法依存、指代消解、局部搭配与全局主题。

变体名称 KV 头数量 KV Cache 显存开销 典型代表模型
MHA (Multi-Head) 与 Query 头数相同 (H) 最高（基准 100%） 原始 Transformer, GPT-3
MQA (Multi-Query) 仅 1 组共享 KV 极低（1/H），偶有质量损失 PaLM, Falcon
GQA (Grouped-Query) 分组共享 (G 组) 折中平衡，兼顾速度与精度 Llama 3, Qwen2.5, Mistral
MLA (Multi-Head Latent) 低秩潜在向量压缩 极低，支持超长上下文推理 DeepSeek-V2 / V3 / R1

PyTorch 极简实现参考

import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class MultiHeadSelfAttention(nn.Module):
    def __init__(self, d_model: int, num_heads: int):
        super().__init__()
        assert d_model % num_heads == 0
        self.num_heads = num_heads
        self.d_k = d_model // num_heads
        self.qkv = nn.Linear(d_model, d_model * 3, bias=False)
        self.out_proj = nn.Linear(d_model, d_model, bias=False)

    def forward(self, x: torch.Tensor, mask: torch.Tensor = None):
        B, T, C = x.shape
        qkv = self.qkv(x).view(B, T, 3, self.num_heads, self.d_k).permute(2, 0, 3, 1, 4)
        q, k, v = qkv[0], qkv[1], qkv[2]  # (B, H, T, d_k)

        scores = torch.matmul(q, k.transpose(-2, -1)) / math.sqrt(self.d_k)
        if mask is not None:
            scores = scores.masked_fill(mask == 0, float("-inf"))

        attn = F.softmax(scores, dim=-1)
        out = torch.matmul(attn, v).transpose(1, 2).contiguous().view(B, T, C)
        return self.out_proj(out), attn
