LoRA 与 QLoRA 高效微调原理及超参数实战指南

用不到 1% 的可训练参数完成大语言模型领域定制：低秩分解数学直觉、NF4 量化显存压缩与调参经验。

核心原理：低秩自适应（Low-Rank Adaptation）

全量微调（Full Fine-Tuning）一个 70B 大模型需要上百 GB 显存来保存权重、梯度以及 AdamW 优化器状态。 LoRA 基于一个关键发现：预训练模型在适配特定下游任务时，权重更新矩阵 ΔW 具有很低的“内在秩”（Intrinsic Rank）。

因此，LoRA 冻结原始预训练权重 W0 ∈ ℝd×k，只在旁路注入两个极小的低秩矩阵 A ∈ ℝr×k 和 B ∈ ℝd×r（其中秩 r ≪ min(d, k)）：

h = W0x + ΔWx = W0x + (α / r) · BAx
  • 零初始化技巧：矩阵 A 使用高斯随机初始化，矩阵 B 初始化为全 0，确保训练起步时 ΔW = BA = 0，完全不破坏原模型能力。
  • 零推理延迟：训练完成后可直接将 W' = W0 + (α / r)BA 合并回原始权重，线上推理不增加任何额外计算量！

QLoRA 的三项核心显存黑科技

QLoRA 在 LoRA 基础上进一步把冻结的基座模型压缩至 4-bit，使单张 24GB 消费级显卡也能微调 30B+ 模型：

  1. 4-bit NormalFloat (NF4)：针对正态分布神经网络权重专门设计的信息论最优 4-bit 量化数据类型，精度远优于普通 INT4。
  2. 双重量化（Double Quantization）：对量化常数本身再进行一次 8-bit 量化，每个参数平均再省下约 0.37 bit 显存。
  3. 分页优化器（Paged Optimizers）：借助 NVIDIA 统一内存机制，在遇到长序列峰值显存 OOM 前自动将部分优化器状态分页卸载到 CPU 内存。
